✅ 微信号可一键复制  

## 本地开发
1. 打开微信开发者工具
2. 导入项目，选择 `E:\codex\我的简历\简历` 目录
3. 点击”编译”，在模拟器预览
4. 点击”预览”，生成二维码真机测试

## 部署前必须配置

### 1. 业务域名配置
在微信小程序管理后台（开发 > 开发管理 > 业务域名）添加：
- `vr.justeasy.cn`（用于 web-view 打开效果图链接）

### 2. 替换 AppID
当前使用测试 AppID：`touristappid`  
正式发布前，在 `project.config.json` 中替换为真实 AppID

## 目录结构
```
├── pages/
│   ├── index/         # 首页
│   ├── case/          # 案例详情
│   └── webview/       # 效果图预览页
├── components/        # 公共组件
│   ├── image-preview/ # 图片预览弹窗
│   ├── contact-bar/   # 联系方式组件
│   └── link-card/     # 链接卡片组件
├── assets/
│   ├── midcentury/    # 金顶公寓（中古风）素材
│   └── modern/        # 蝶湖一号（现代风）素材
└── utils/
    └── portfolio.js   # 数据配置文件
```

## 后续修改
- 添加案例：在 `utils/portfolio.js` 的 `cases` 数组中新增
- 修改联系方式：在 `portfolio.js` 的 `contact` 对象中修改
- 更新效果图链接：在 `kujialeLinks` 数组中修改
